如何使用：
把被混淆的epub放到和Main.py同一目录下，然后运行Main.py。

将epub内名称被混淆成.|*?之类组合的文件及其索引路径恢复成普通名称，使得阅读软件可正常读取。
该类混淆的例子有:比如基于多看标准制作的加密epub，使得只能在在多看上看而其它软件会打不开或提示drm保护。

须知：
有些epub的文章加密方式是：原始文本就是乱码，通过使用e书自己附带的解密字体来一一对应进行重渲染。
然后特定阅读软件支持使用e书指定的字体，从而显示正常内容，否则就是乱码。比如多看就可以这样做。
即便预览是正常的，但复制文字就会发现变乱码了。
这种加密方式下，如果只是希望能正常阅读，可以用支持使用e书附带字体的软件来解决。
